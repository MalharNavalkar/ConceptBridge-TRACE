# Curriculum source notes

The lesson material is original teaching copy, cross-checked against the following sources. Equations, tables, and simulations are also verified in project tests.

| Lesson | Primary/reference source | Rules cross-checked |
|---|---|---|
| Logic Gates Fundamentals | [IIT Roorkee Virtual Labs — gate truth tables](https://de-iitr.vlabs.ac.in/exp/truth-table-gates/theory.html) | AND, OR, NOT, NAND, NOR, XOR and XNOR definitions; XOR is 1 for different inputs and XNOR for equal inputs. The lesson fixes the common source-page notation slip by defining NAND=¬(A·B), NOR=¬(A+B), and XNOR=¬(A⊕B). |
| Binary Number Systems | [NJIT Open Textbook — Digital Systems and Numbers](https://digitalcommons.njit.edu/cgi/viewcontent.cgi?filename=0&article=1000&context=oat&type=additional); [Cornell — Two's Complement](https://www.cs.cornell.edu/~tomf/notes/cps104/twoscomp.html) | Place-value weights, repeated division conversion, unsigned n-bit range 0..2ⁿ−1, two’s-complement range −2ⁿ⁻¹..2ⁿ⁻¹−1, and invert-plus-one negative encoding. |
| Boolean Algebra and Simplification | [All About Circuits — DeMorgan’s Theorems](https://www.allaboutcircuits.com/textbook/digital/chpt-7/demorgans-theorems/) | Complementing grouped AND/OR expressions swaps the operator and complements each operand; maintain grouping. Absorption A+AB=A is checked row by row. |
| Half Adder and Full Adder | [IIT Roorkee Virtual Labs — Half/full adders](https://de-iitr.vlabs.ac.in/exp/half-full-adder/theory.html) | Half adder Sum=A⊕B, Carry=AB; full adder Sum=A⊕B⊕Cin and Cout=AB+ACin+BCin (majority). Every 4-row/8-row table is programmatically cross-checked. |
| Multiplexers and Demultiplexers | [IIT Roorkee Virtual Labs — MUX/DEMUX](https://de-iitr.vlabs.ac.in/exp/multiplexer-demultiplexer/theory.html) | 4:1 MUX selects D0..D3 using the explicitly stated S1 high-order/S0 low-order convention; 1:4 DEMUX sends D to the addressed active-high output. |
| Encoders and Decoders | [IIT Roorkee Virtual Labs — encoder/decoder](https://de-iitr.vlabs.ac.in/exp/decoder-demultiplexer-encoder/theory.html) | 2:4 decoder has one active-high output per address when enabled; simple 4:2 encoder assumes one-hot input. Priority encoding is called out as a separate behavior, not silently assumed. |
| SR, JK, D and T Flip-Flops | [IIT Roorkee Virtual Labs — flip-flop characteristic tables](https://de-iitr.vlabs.ac.in/exp/truth-tables-flip-flops/theory.html) | Active-high SR 11 is invalid; JK 11 toggles; D captures D; T toggles when T=1. The copy explicitly says device polarity/clocking details vary and a real datasheet controls. |
| Counters and Registers | [All About Circuits — Synchronous Counters](https://www.allaboutcircuits.com/textbook/digital/chpt-11/synchronous-counters/); [Wayne State ECE — Registers and Counters (PDF)](https://ece.eng.wayne.edu/~smahmud/ECECourses/ECE2610/LectureNotes/Lecture12.pdf) | n flip-flops store n bits; a counter is a register following a state sequence; synchronous stages share a clock, while ripple stages propagate clock transitions; modulo-16 four-bit next-state wrap is explicit. |

All Hindi and Hinglish copy is written as learner-facing draft language and should receive fluent technical-educator review before formal classroom use. These references are educational sources; this app does not reproduce their diagrams or text.
